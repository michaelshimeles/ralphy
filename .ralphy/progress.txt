### Implement --engines CLI argument parsing in parse_args()

**Location:** ralphy.sh:712-748

**What was implemented:**
1. Added `ENGINES` array and `ENGINE_WEIGHTS` associative array variable declarations (lines 48-49)
2. Implemented `--engines` argument parsing in parse_args() function (lines 712-748)

**Features:**
- Parses comma-separated list of engines into ENGINES array
- Supports weight syntax: `engine:weight` (e.g., `claude:5`)
- Validates that weights are positive integers (rejects zero and negative values)
- Supports engine names without weights (defaults to weight of 1)
- Allows alphanumeric engine names with hyphens and underscores
- Provides clear error messages for invalid specifications

**Examples:**
- `--engines claude` → ENGINES=(claude), ENGINE_WEIGHTS[claude]=1
- `--engines claude:5` → ENGINES=(claude), ENGINE_WEIGHTS[claude]=5
- `--engines claude:3,opencode,cursor:2` → ENGINES=(claude opencode cursor), ENGINE_WEIGHTS[claude]=3, ENGINE_WEIGHTS[opencode]=1, ENGINE_WEIGHTS[cursor]=2

**Validation:**
- Engine names must match pattern: `^[a-zA-Z0-9_-]+$`
- Weight syntax must match pattern: `^([a-zA-Z0-9_-]+):([0-9]+)$`
- Weights must be positive integers (> 0)
- Invalid formats are rejected with error messages

### Update --help output with --engines and --engine-distribution flags

**Location:** ralphy.sh:619-629 (multi-engine options), ralphy.sh:662-668 (examples)

**What was implemented:**
1. Added new "MULTI-ENGINE OPTIONS" section to help output (lines 619-629)
2. Added multi-engine examples to the EXAMPLES section (lines 662-668)

**Documentation Added:**
- `--engines LIST`: Comma-separated list of engines with optional weight syntax
  - Format: `engine1:weight1,engine2:weight2,...`
  - Example: `--engines claude:3,cursor:1,opencode:2`
  - Default weight of 1 for engines without explicit weight

- `--engine-distribution STRATEGY`: Distribution strategy for multi-engine execution
  - `round-robin`: Cycle through engines sequentially (default)
  - `weighted`: Distribute based on engine weights
  - `random`: Randomly assign engines
  - `fill-first`: Fill one engine before moving to next

**Examples Added:**
1. Basic multi-engine with round-robin: `./ralphy.sh --parallel --engines claude,cursor,opencode`
2. Weighted distribution: `./ralphy.sh --parallel --engines claude:5,cursor:1 --engine-distribution weighted`
3. Fill-first strategy: `./ralphy.sh --parallel --engines claude,codex --engine-distribution fill-first`

**Testing:**
- Verified help output formatting with `grep` and `sed` commands
- Confirmed multi-engine section appears correctly in help
- Confirmed examples section includes multi-engine usage patterns
