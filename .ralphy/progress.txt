### Implement --engines CLI argument parsing in parse_args()

**Location:** ralphy.sh:712-748

**What was implemented:**
1. Added `ENGINES` array and `ENGINE_WEIGHTS` associative array variable declarations (lines 48-49)
2. Implemented `--engines` argument parsing in parse_args() function (lines 712-748)

**Features:**
- Parses comma-separated list of engines into ENGINES array
- Supports weight syntax: `engine:weight` (e.g., `claude:5`)
- Validates that weights are positive integers (rejects zero and negative values)
- Supports engine names without weights (defaults to weight of 1)
- Allows alphanumeric engine names with hyphens and underscores
- Provides clear error messages for invalid specifications

**Examples:**
- `--engines claude` → ENGINES=(claude), ENGINE_WEIGHTS[claude]=1
- `--engines claude:5` → ENGINES=(claude), ENGINE_WEIGHTS[claude]=5
- `--engines claude:3,opencode,cursor:2` → ENGINES=(claude opencode cursor), ENGINE_WEIGHTS[claude]=3, ENGINE_WEIGHTS[opencode]=1, ENGINE_WEIGHTS[cursor]=2

**Validation:**
- Engine names must match pattern: `^[a-zA-Z0-9_-]+$`
- Weight syntax must match pattern: `^([a-zA-Z0-9_-]+):([0-9]+)$`
- Weights must be positive integers (> 0)
- Invalid formats are rejected with error messages
