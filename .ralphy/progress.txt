### Implementation Details

The get_engine_for_agent() function implements round-robin distribution by:
- Calculating engine_index = agent_num % engine_count
- Returning the engine at that index from the ENGINES array
- This ensures even distribution across all configured engines
- Agent 0 gets ENGINES[0], agent 1 gets ENGINES[1], etc.
- After reaching the last engine, it cycles back to the first
