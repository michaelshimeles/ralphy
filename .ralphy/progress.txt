### Implementation Details

The random distribution strategy:
- Uses bash's built-in $RANDOM variable (0-32767 range)
- Applies modulo operation: engine_index = RANDOM % engine_count
- Each call to get_engine_for_agent() produces a new random selection
- Provides non-deterministic engine assignment across agents
- Useful for load balancing and avoiding patterns in engine usage
