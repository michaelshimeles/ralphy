Improved error messages for multi-engine support:

1. Unknown engine error - Now lists valid options
   - Added VALID_ENGINES array with all supported engines
   - validate_engines() checks against this list and shows valid options on error
   - Error message format: "Unknown engine(s): <invalid> / Valid engines are: claude opencode cursor codex qwen droid"

2. Invalid weight error - Shows expected format
   - --engines argument parser validates weight format
   - Checks weights are positive integers (> 0)
   - Error messages:
     * "Invalid weight for engine 'X': weights must be positive integers (got: Y)"
     * "Expected format: --engines engine:weight (e.g., claude:2,cursor:1)"
     * "Invalid engine specification: 'X'"
     * Shows examples for proper format

3. No valid engines error - Suggests solutions
   - validate_engines() filters engines to only those with available CLIs
   - If no engines remain after filtering, shows comprehensive error:
     * "No valid engines available."
     * Lists all valid engines with installation links
     * Suggests verifying CLI is in PATH
     * Suggests trying different engine flags

4. Missing CLI error - Shows installation hints
   - validate_engines() warns about missing CLIs with installation instructions
   - Each engine has specific installation hint:
     * Claude: https://github.com/anthropics/claude-code
     * OpenCode: https://opencode.ai/docs/
     * Cursor: Install Cursor and ensure 'agent' is in PATH
     * Codex: Ensure 'codex' is in your PATH
     * Qwen: Ensure 'qwen' is in your PATH
     * Droid: https://docs.factory.ai/cli/getting-started/quickstart
