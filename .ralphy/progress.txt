### Implementation Details

The fill-first distribution strategy works by:
- Calculating agents_per_engine using ceiling division: (total_agents + engine_count - 1) / engine_count
- Assigning agents sequentially to engines until each engine is filled
- Example with 3 engines and 10 agents:
  - agents_per_engine = ceil(10/3) = 4
  - Agents 0-3 → engine 0 (claude)
  - Agents 4-7 → engine 1 (opencode)
  - Agents 8-9 → engine 2 (cursor)
- This fills the first engine completely before moving to the next
- Prevents out-of-bounds access with: if (engine_index >= engine_count) engine_index = engine_count - 1
